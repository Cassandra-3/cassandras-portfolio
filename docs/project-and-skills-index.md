## Evidence terminology

- **Professional:** performed in paid employment or formal work placement.
- **Academic:** completed as part of a program or course.
- **Personal:** independently created outside employment or coursework.
- **Implemented:** supported by code, configuration, output, or another verifiable artifact.
- **Designed:** documented architecture, workflow, policy, or recommendation without deployment evidence.
- **Planned:** not yet completed and should not be represented as finished work.
